# OneDayTrip
App for generating one day trips in the city
iOS - SwiftUI based 

Design: 
<img width="1536" height="1024" alt="DayTrip Mobile App Storyboard" src="https://github.com/user-attachments/assets/aa2b47d0-ab9e-416f-a55f-59a2826a5909" />
For the design stage, I created an initial Figma storyboard to understand the structure of DayTrip before coding. I focused mainly on the navigation flow, information hierarchy, and the main screens rather than detailed visual styling. I also used existing apps such as Wanderlog and Google Maps as model deliverables to understand how they organize stops, timing, and location information. The goal of the design was to reduce uncertainty and make the SwiftUI implementation more organized.
